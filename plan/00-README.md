## Rules that apply to every job

**Never type a statistic into a page.** Import `summary.json`. If the figure you
need is not in it, extend `scripts/build_summary.py`. This is not a style
preference — `CheckPD_Local_Agent_Context.md` §23 rule 9 forbids reporting counts
not derived from the release files.

**Unknown values render as a visible `Pending`.** License, DOI, IRB number, author
list, DUA terms and contact email are not decided yet. Never invent a plausible
value, and never drop the row — an absent row reads as "not applicable", which is
a different and wrong claim.

**Never list individual filenames.** They contain subject IDs.

**v2.0 is PD vs HC only.** The word "prodromal" must not appear anywhere.

**English for the dataset record.** The landing page, files, modality
documentation and citation stay English. Thai exists only on the orientation
pages under `/th/` — do not translate a dataset page without adding a `PAIRS`
entry in `src/data/i18n.ts` and recording the decision.

**One dependency.** No charting library, no UI framework, no icon package. Charts
are plain HTML and CSS. Adding a dependency requires an entry in
[`../../docs/DECISIONS.md`](../../docs/DECISIONS.md).

## Definition of done for every job

```bash
npm run build
grep -rlE '\bS[0-9]{4}\b|\b[0-9]{13}\b|[a-zA-Z0-9._%+-]+@[a-zA-Z0-9.-]+\.[a-z]{2,}' dist/
```

- [ ] No number on the page was typed by hand.
- [ ] 400 px wide: no horizontal scroll on `body`.
- [ ] White light theme is the default; light and dark both work through the toggle.
- [ ] Every chart has a legend and a table view.
- [ ] Unknown values show `Pending`.
- [ ] Append to [`../../docs/CHANGELOG.md`](../../docs/CHANGELOG.md); update the
      task status in [`../../docs/PLAN.md`](../../docs/PLAN.md).
